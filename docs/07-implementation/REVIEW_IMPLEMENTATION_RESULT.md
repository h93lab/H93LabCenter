# نتيجة تنفيذ المراجعات — 2026-09-08

تم تنفيذ نطاق خطة المراجعة المعتمدة داخل H93LabCenter. التطبيق يعمل محليًا على http://127.0.0.1:5178، مع API مشترك على 8788 وSupabase Edge Runtime على 55325. النشر السحابي لم يُنفذ.

## ما تغير

- حفظ التحليل والتوصية وإنهاء العمل في معاملة واحدة محمية برقم المحاولة. فشل أي كتابة يعيد المعاملة كاملة. توليد Blueprint يربط النسخة بالعمل ويضيف مهمة المراجعة في نفس المعاملة.
- احترام الصفر في ميزانيات الدور والتشغيل؛ حدود يومية اختيارية للتكلفة وعدد استدعاءات كل دور؛ قبول النموذج المجاني عند تأكيد سعره في الكتالوج.
- فرض قواعد المنع السبع، ومنع pass/fail بلا دليل في عقد الاستجابة نفسه. rubric 1.1 يوضح اتجاه عوامل المنافسة وعبء المحتوى. إعادة محاولة 429 والشبكة محدودة وتحترم Retry-After.
- دمج مفاهيم التشغيل دون استبدال إحصاءاتها، وقراءة التاريخ الطويل ونتائج التشابه دون إسقاط السجلات بعد أول 100 عنصر.
- مكتبة أفكار قابلة للتصفية والمقارنة، مع ربط كل توصية بدرجتها وثقتها الصحيحتين. عرض الأسواق، المنافسين ومصادر التغير، وعلاقات الأدلة المتعارضة، وخطوة التحقق التالية.
- بحث مخصص لفكرة موجودة، واستيراد CSV/JSON للمراجعات مع المعاينة والتحقق ومنع التكرار، وسجل تحقق يدوي مرتبط بالأدلة. المستورد موسوم بأنه مقدم من المالك وليس موثقًا باستقلالية.
- إصلاح التركيز والحوارات والتبويبات والتنقل بالكيبورد، وروابط المستندات والإصدارات، وعرض الفروق بما فيها الحذف، وتحسين العرض على 320/390/768 بكسل وثلاثة إطارات للـprototype.
- فحص كل ملفات ZIP وJSON وMANIFEST ومساراتها وروابطها؛ لا يصل إصدار جديد إلى Ready for Development قبل إنشاء حزمة في Storage خاص.

## نتائج التحقق

- `npm run check`: lint وTypeScript و20 اختبار وحدة/عقد وproduction build ناجحة.
- `npm run test:integration`: 13 مجموعة تحقق ناجحة، تشمل عزل مالكين، rollback، المحاولات القديمة، إعادة الإرسال، الميزانية صفر، الاستيراد، 106 إصدارات و106 درجات، ودمج DEDUPE متزامن.
- `npm run test:browser`: 5 اختبارات ناجحة؛ تسجيل الدخول، الواجهة المتجاوبة، المستندات والإصدارات، المقارنة، التبويبات، معاينة الاستيراد وميزانية صفر. اختبار مقارنة الملف الوحيد يتأكد من حالة فتحه قبل النقر، لأنه يفتح تلقائيًا.
- Edge Runtime: المصادقة، رفض worker غير المصرح، منع التسجيل العام، تصدير ZIP وتنزيله مع مطابقة SHA-256 لكل الملفات نجحت.
- `supabase db lint --local`: لا أخطاء؛ تحذير واحد عن معامل `p_key` غير المستخدم في `center_go`، الذي يمنع تكرار المشروع اعتمادًا على concept وقفل المعاملة.
- أربعة migrations إضافية طُبقت محليًا؛ أنواع قاعدة البيانات ونسخ runtime schemas محدثة. Cron الخاص بالعامل والموزع نشط؛ لا توجد أعمال محلية عالقة عند الفحص الأخير.
